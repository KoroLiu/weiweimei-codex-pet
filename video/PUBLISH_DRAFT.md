# 投稿文案初稿

标题：把维维美装进 Codex！附下载与安装教程

简介：

给你的 Codex 添一位小伙伴——维维美！

本期带你下载项目、预览角色动作，并在支持自定义宠物的 Windows Codex 桌面客户端里安装这只 Q 版宠物。

项目地址与使用说明：https://github.com/KoroLiu/weiweimei-codex-pet

直接下载 ZIP：https://github.com/KoroLiu/weiweimei-codex-pet/archive/refs/heads/main.zip

下载后先解压，打开 final/index.html 可以预览，再按视频步骤安装。安装宠物不需要额外安装 Python 或 TTS 模型。

谢谢大家，我们下期再见！

可直接复制的简介另存为 exports/video-description.txt。以下内容供发布者参考，不必全部复制进简介。

安装路径：`%USERPROFILE%\.codex\pets\weiweimei\`，里面直接放 `pet.json` 和 `spritesheet.webp`。若设置了 `CODEX_HOME`，改用其目录下的 `pets`。
